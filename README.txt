1. Install Android Studio (developer.android.com/studio).
2. File > Open > pick this TriageFlowAndroid folder. Wait for Gradle sync (first time downloads stuff).
3. If it offers to update Gradle/plugin versions, accept.
4. Press the green Run button (emulator or a phone with USB debugging).
Your web app files live in app/src/main/assets. Edit them there.
Build APK: Build > Build Bundle(s) / APK(s) > Build APK(s).
